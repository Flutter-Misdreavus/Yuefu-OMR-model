# 关于乐府
乐府是第十九届全国大学生软件创新大赛全国赛二等奖作品，是一款为全世界音乐学习者量身打造的伟大应用(掌声)！
具体的功能有:
- 通过拍照或图片，智能识别五线谱，包括音高、拍号、速度、调号等元素
- 根据所识别的乐谱，生成可视化钢琴键盘瀑布流
想要进一步了解乐府？请前往 [项目展示页面](https://github.com/Flutter-Misdreavus/yuefu-presentation)

# 关于此项目
本项目是乐府OMR(光学音乐识别)的模型部分，使用的是开源的Legato模型，用于将乐谱图像转化为ABC符号。
具体使用请阅读 [API文档](docs/API.md)
